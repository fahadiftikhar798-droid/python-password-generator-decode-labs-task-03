# 🔐 Python Password Generator — DecodeLabs Internship (Task 3)

A secure and customizable Command Line Interface (CLI) **Random Password Generator** built using Python as part of Task 3 during my **DecodeLabs Internship**.

---

## 🚀 Features

* **Customizable Length:** Allows users to define their preferred password length with strict validation.
* **Balanced Character Pool:** Combines lowercase letters, uppercase letters, digits, and special punctuation symbols (`string` module).
* **Cryptographic Security:** Uses Python's built-in `secrets` module for cryptographically strong random selection.
* **Input Validation & Error Handling:** Uses `try/except` blocks and loops to safely handle non-integer or out-of-range user inputs.
* **Clean & Modular Code:** Organized with reusable functions and standard Python script entry points (`if __name__ == "__main__":`).

---

## 🛠️ Tech Stack

* **Language:** [Python 3](https://python.org)
* **Standard Libraries:** `secrets`, `string`
